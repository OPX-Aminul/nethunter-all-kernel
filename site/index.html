Find a kernel for your phone

Device names, codenames, source counts, fork counts, feature evidence and a recommended kernel for each model. Built from the verified research dataset.

Download buttons open the maintainer's release page, or a direct ZIP/IMG file when the latest release publishes one. This site does not host kernel files.

How to read this list

  • Sources counts distinct kernel source repositories for that device/codename. Forks is the sum of GitHub fork counts where metadata exists.
  • Recommended is selected from the available kernels using boot evidence, feature evidence, maintenance date and repository activity. It is a research recommendation, not a guarantee.
  • Download opens a mirrored copy of the developer ZIP/IMG when available, then the original file, then the source release page. Files marked Mirror are hosted in this repository releases; they were not rebuilt or independently boot-tested.
  • Kernels counts kernel records for the device. Releases sums the release/tag counts reported by each source. Prebuilt counts kernels with a direct developer file. Build needed counts source-only kernels with no prebuilt ZIP/IMG.
  • Per-kernel status shows boot evidence, working evidence, direct files, guide source, release count, ROM note, recovery, root/bootloader requirements, and Android version. Unknown means the source did not state it.
  • Installation guide shows requirements, flashing steps, file type (ZIP, boot IMG, TAR archive), channel (stable/beta), and customization claims. Requirements/customizations come from the README where available; flashing steps are README-derived or explicitly labeled generic file-type guidance.
  • Evidence levels: developer-reported test, claimed by developer, config/driver evidence, or unknown. No row is independently verified. Customization lists are claims or source/config evidence, not test results.

Research dataset generated 2026-10-19. Source data: nethunter_master.csv.

Always match the exact codename, ROM and model variant before flashing. Flashing a wrong kernel can brick a device.
