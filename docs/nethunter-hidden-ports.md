## How to use this list

1. Match the exact codename and ROM before flashing.
2. Read the repository build instructions and branch names; many are tied to one LineageOS/crDroid release.
3. Treat boot and feature claims as leads to reproduce, not as guarantees.
4. If you test one, record the ROM build, kernel commit, adapter/chipset, and result.
